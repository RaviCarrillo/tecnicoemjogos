# The Resistance - Uma Rodada com 5 Jogadores

## Configuração Inicial
- **5 jogadores** recebem identidades secretas
- **Distribuição**: 3 Agentes da Resistência e 2 Espiões
- Cada jogador vê sua carta, mas não vê a dos outros

## Passo a Passo de UMA RODADA

### 1. **Seleção do Líder**
- Um jogador é designado como "Líder da Missão"
- O líder muda a cada rodada (sentido horário)

### 2. **Proposição do Líder**
- O Líder escolhe **3 jogadores** para ir na missão (incluindo a si mesmo se quiser)
- O Líder anuncia sua seleção

### 3. **Votação da Equipe**
- **Todos os 5 jogadores votam** se aprovam ou rejeitam a equipe proposta
- Votam simultaneamente (mostrando polegar para cima ou para baixo)
- **Precisa de maioria simples** para aprovação
- Se REJEITAR: volta ao passo 1, próximo jogador vira Líder

### 4. **Execução da Missão** (se aprovada)
- Os **3 jogadores selecionados** participam da missão
- **Em segredo**, cada um escolhe:
  - Carta de **SUCESSO** (azul) - quer que a missão suceda
  - Carta de **SABOTAGEM** (vermelha) - quer que a missão falhe
- Colocam as cartas viradas para baixo

### 5. **Revelação do Resultado**
- As 3 cartas são reveladas
- **REGRA**: Se houver **QUALQUER carta vermelha (sabotagem)**, a missão **FALHA**
- Se todas forem azuis, a missão **SUCEDE**
- O resultado é registrado no placar

### 6. **Passagem do Líder**
- O Líder passa para o jogador seguinte
- A rodada termina

---

## O Que Cada Lado Quer

| **Resistência** | **Espiões** |
|---|---|
| Fazer 3 missões succerem | Fazer 3 missões falharem |
| Descobrir quem são os Espiões | Permanecer escondidos |
| Confiar nos aliados | Voto estratégico para missões falsas |

---

## Exemplo Prático com 5 Jogadores (A, B, C, D, E)

1. **Líder = A** → Propõe equipe: {A, B, C}
2. **Votação**: A, B, C, D, E votam → Aprovam ✓
3. **Missão**: A, B, C colocam cartas secretas
4. **Resultado**: B (Espião) coloca Sabotagem → Missão **FALHA** ✗
5. **Próximo**: Líder = B → Propõe nova equipe...

---

## Fim da Rodada
A rodada termina quando um time conseguir **3 vitórias consecutivas** (Resistência ganha) ou **3 derrotas** (Espiões ganham).
